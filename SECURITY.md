# Security policy

## Supported versions

Security fixes are made for the latest release only.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub instead: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include the version you tested, the steps to reproduce the problem, and what an attacker could do with it. You should get a reply within 7 days. Once a fix is released, the report can be made public, with credit to you if you want it.
